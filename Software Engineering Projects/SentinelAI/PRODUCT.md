# SentinelAI
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated by the user's master implementation brief. FastAPI, SQLite for a portable single-host FYP installation, and React with TypeScript. No prior source files were present. PostgreSQL deployment is a later migration, not an implemented claim.

## Users
Citizens and officers submit and contest evidence. Supervisors investigate and make decisions. Control-room staff manage safety alerts. Administrators manage access and governance.

## Product Purpose
Support fair, evidence-centered human review of Pakistani police interactions and safety concerns. Never determine guilt or automatically contact emergency services.

## Operating Context
Local FYP demonstration with explicitly synthetic scenarios; consent-based uploads. The primary desktop task is investigation; mobile supports capture and essential actions.

## Capabilities and Constraints
The PRD is authoritative. Model output, simulated fixtures, observed evidence, unavailable analysis, and human decisions must remain distinguishable. Real model evaluation requires an authorized labeled dataset. External delivery requires an actual configured integration.

## Brand Commitments
Deep navy/slate navigation, neutral work surfaces, restrained teal actions, amber uncertainty, red urgent safety states. Consistent icons, readable density, keyboard access, responsive layouts.

## Evidence on Hand
The supplied October 2026 PRD. No source code, existing media, trained weights, real footage, or production credentials.

## Product Principles
- Evidence references precede conclusions.
- Human oversight is mandatory for uncertain and serious findings.
- Missing analysis never means a normal interaction.
- Private media is authorized and audited at the server.
- Demonstration data cannot masquerade as real inference.

## Accessibility & Inclusion
Keyboard operation, visible focus, text risk labels, accessible forms, Urdu-script display and responsive mobile capture.
