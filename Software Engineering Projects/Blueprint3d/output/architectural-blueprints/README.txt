HOW TO TEST
Upload a PNG to test recognition. Choose feet and enter the overall plot width and length above if automatic scale is uncertain. Review the draft against the drawing.
Import its matching JSON for the designed reference geometry. The PNG and JSON share walls, openings and clear room extents. PNG symbols include bathroom fixtures and kitchen counters; the matching JSON contains architectural geometry, not individual fixture meshes. Press Suggest furniture to add editable furnishings.

The four-page vector PDF prints on A3. Print at 100 percent to retain the indicated scale.
Dimensions next to room names are clear bounding extents. MAX identifies irregular rooms. Outer dimension chains use wall centre lines and therefore differ from clear room dimensions by wall thickness.

These are original concept/app-test drawings, not approved construction documents. A separate upper-floor drawing is needed for the stair connection.
